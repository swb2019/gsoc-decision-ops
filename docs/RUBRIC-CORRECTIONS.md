# Glasshouse contract correction history

## kernel-1.1.0 — explicit voluntary end

Fresh practice can end through a deliberate confirmation with a bounded reason. The terminal lifecycle is `abandoned`, distinct from an active partial record, an incomplete handoff or a completed scenario. Ending preserves the exact simulated tick, evidence, decisions, resources, pending queue, controls and ledger. The reason and a single terminal event are retained; operational commands cannot resume that run. The action grants no handoff completion or competence result.

The new command is unavailable in `kernel-1.0.0`. Historical replay retains that original rule version, including its original lifecycle interpretation. The browser offers read-only inspection and export for any supported noncurrent contract, then a separate fresh run for current practice.
